# Coding Music Portfolio

This repository contains weekly assignments for the Coding Music course. The projects are written in [ChucK](https://chuck.stanford.edu/).

## Assignments

| Week | Project | Files |
| --- | --- | --- |
| 1 | Basic oscillators and randomization | Assignment and practice `.ck` files |
| 2 | Repeating two-oscillator note sequence | One assignment `.ck` file |
| 3 | Layered melody, bass, panning, and note arrays | One assignment `.ck` file |
| 4 | Sample-based rhythmic composition with synth layers | One assignment `.ck` file and its required audio samples |
| 5 | Midterm composition | One midterm `.ck` file |

## Running the projects

Install ChucK, open a terminal in the repository, and run the file for the desired week. For example:

```bash
chuck week-04/coding-music-week-04-assignment.ck
```

Some assignments repeat continuously. Stop playback with `Ctrl+C`.
